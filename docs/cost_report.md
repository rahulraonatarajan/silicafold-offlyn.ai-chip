# SilicaFold V0 - Cost Report

## Tiny Tapeout Cost Estimates

This document provides estimated costs for submitting SilicaFold V0 to Tiny Tapeout. These are estimates based on publicly available Tiny Tapeout pricing; actual costs may vary.

**Important**: Verify current pricing at [tinytapeout.com](https://tinytapeout.com) before submission.

## What's Included

Tiny Tapeout submission typically includes:
- Silicon fabrication on shared shuttle
- GDSII tapeout processing
- Post-fabrication testing (basic)
- PCB/DevKit for testing (if ordered)
- Documentation integration

## What's NOT Included

The above costs do NOT include:
- Development tools (open source tools available)
- Testing equipment beyond DevKit
- External components for testing
- Multiple PCB units
- Expedited shipping
- Custom packaging

## Warning

**Do not use concept-image values as real PPA metrics.**

OpenLane/OpenROAD metrics (area, timing, power) must be generated by the actual hardening flow. The only valid PPA data comes from:
- GitHub Actions GDS workflow artifacts
- Local OpenLane runs
- Tiny Tapeout build reports

Conceptual estimates or hand-drawn diagrams are NOT valid PPA sources.

## Verification Checklist

Before committing to a tile count:
- [ ] Run GDS workflow successfully
- [ ] Check actual utilization from OpenLane reports
- [ ] Verify timing closure at target frequency
- [ ] Review DRC/LVS results
- [ ] Confirm no synthesis errors or warnings
