# GDS Artifacts Guide

## Overview

This document explains where to find generated GDS and related artifacts after the GitHub Actions GDS workflow completes successfully.

## GitHub Actions Artifacts

After the GDS workflow runs, artifacts are available for download from the GitHub Actions interface.

### Accessing Artifacts

1. Go to the repository on GitHub
2. Click the "Actions" tab
3. Select the completed "GDS" workflow run
4. Scroll down to "Artifacts" section
5. Download the desired artifact ZIP files

### Available Artifacts

#### `gds` Artifact
Contains the final GDS layout file:
- `*.gds` - Uncompressed GDS file
- `*.gds.gz` - Compressed GDS file (if applicable)

Location in artifact: `runs/wokwi/results/final/gds/`

#### `openlane-run` Artifact
Contains the complete OpenLane run directory:
- All intermediate results
- Log files
- Configuration used
- Temporary files

This is a large artifact useful for debugging.

#### `reports` Artifact
Contains synthesis and physical design reports:
- `synthesis/` - Yosys synthesis reports
- `routing/` - Routing statistics
- `signoff/` - Final DRC/LVS reports

## Viewing GDS Files

### KLayout (Recommended)
1. Download [KLayout](https://www.klayout.de/)
2. Open the .gds file
3. Use layer panel to toggle visibility
4. Zoom to see standard cells

### Online Viewers
- GDS2WebGL viewers (if generated)
- Online GDSII viewers (limited functionality)

### Magic VLSI
```bash
magic -T sky130A.tech
# Then: File -> Read GDS
```

Use the provided Python script:


## Common Issues

### Artifact Not Found
- Workflow may have failed before GDS generation
- Check workflow logs for errors
- Verify the workflow completed (green checkmark)

### GDS File Too Large
- GDS files can be tens of MB
- Use compressed version if available
- Consider GDS streaming for very large files

### Reports Missing Expected Metrics
- Some metrics only appear if relevant
- DRC might be empty if clean
- Power estimates may require additional setup

## Retention

GitHub Actions artifacts have limited retention:
- Default: 90 days for GDS
- Default: 30 days for reports
- Download important artifacts before expiration

## Local Storage

After downloading and verifying artifacts:

1. Copy key reports to `reports/` directory
2. Document actual metrics in README
3. Store GDS reference (don't commit large files)
4. Update submission checklist

## Not Included in Artifacts

The following are NOT generated by the basic GDS workflow:
- Detailed power analysis (requires simulation)
- Actual timing with real parasitics (post-layout simulation)
- Thermal analysis
- Full signoff (requires commercial tools)

These require additional tools or manual analysis.
